## 1. Проблема
Дан отсортированный связный список. Нужно удалить все дубликаты, чтобы каждое число встречалось только один раз.

## 2. Как я решал
Так как список уже отсортирован, все одинаковые числа стоят рядом.
1. Я создал указатель `current`, который ставится в начало списка (`head`).
2. Запустил цикл. Проверяю: если значение текущего узла равно значению следующего, я просто "перепрыгиваю" следующий узел, меняя ссылку на один вперед.
3. Если значения разные, я просто двигаю указатель дальше.
4. В конце возвращаю начало списка.

Я не стал использовать дополнительные структуры данных, так как это усложнило бы код, а тут можно справиться просто меняя связи между узлами.

## 3. Сложность
- **Время:** O(n). Я прохожу по списку ровно один раз от начала до конца.
- **Память:** O(1). Я использую только одну переменную-указатель, новая память не выделяется.

## 4. Улучшения
- **Можно ли сделать лучше?** Нет, алгоритм уже оптимальный, быстрее чем за O(n) эту задачу не решить, так как нужно посмотреть каждый элемент хотя бы один раз.
