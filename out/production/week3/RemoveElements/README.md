## 1. Проблема
Дан список и число. Нужно удалить из списка все узлы, у которых значение равно этому числу.

## 2. Как я решал
Самая большая проблема в таких задачах — что делать, если нужно удалить самый первый элемент (head)? Чтобы не писать кучу проверок типа `if (head.val == val)`, я использовал стандартный трюк: создал фиктивный узел (dummy), который поставил перед списком.
1. Указатель `current` начинает с фиктивного узла.
2. Я всегда смотрю на один элемент вперед (`current.next`).
3. Если там "плохое" число, я просто меняю ссылку, чтобы обойти его.
4. В конце возвращаю `dummy.next` — это и есть наше новое начало списка.

## 3. Сложность
- **Время:** O(n). Мы проходим по списку один раз.
- **Память:** O(1). Мы создали только один дополнительный фиктивный узел.

## 4. Улучшения
- **Можно ли сделать лучше?** Алгоритм оптимален. Использование dummy-узла — это самая правильная и понятная практика для этой задачи. Менять ничего не нужно.
