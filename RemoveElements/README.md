1. Проблема
Надо выкинуть из списка заданное число

2. Как решал
Чтобы не возиться с первым элементом я добавил фейковый узел в начало. Иду и смотрю на шаг вперед. Если вижу то самое число то перепрыгиваю его. В конце возвращаю нормальный список
3. Сложность
Время O(n) прошел один раз
Память O(1) создал всего один узел
